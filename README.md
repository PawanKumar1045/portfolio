# portfolio
A personal portfolio website and projects showcase.

## Local preview
This is a static site with no build step.

- Quick open: open `/home/runner/work/portfolio/portfolio/index.html` in a browser.
- Local server option:
  ```bash
  cd /home/runner/work/portfolio/portfolio
  python -m http.server 8000
  ```
  Then open `http://localhost:8000`.

## Resume file placement
The resume download button points to:

- `assets/Bhavani_Sankar_Resume.pdf`

Place your actual resume PDF at that exact path to enable downloads.

## Content replacement checklist
The current portfolio intentionally uses placeholders because resume internals provided were not machine-readable text.

Replace these placeholders with verified details from readable resume content:

- [ ] Professional headline and hero summary
- [ ] About section summary
- [ ] Skills and technology stack chips
- [ ] Featured project titles, outcomes, links, and tech tags
- [ ] Experience and education timeline entries
- [ ] Certifications/achievements entries
- [ ] Contact links (email, LinkedIn, GitHub)
